# wg-display-widget-sdk

WIT interface and guest bindings for [WG Display](https://github.com/Siryll/wg_display_embedded_multi) widgets. Use by the [Widget Template](https://github.com/Siryll/wg_display_embedded_widget_template), check the Template for how to create your own widgets.

## Versioning

Versioning done via tags that allign with wg-display-multi major changes.
